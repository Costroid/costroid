# Your account on costroid.com

The comment Costroid posts on a pull request links here when the report names no account.

Costroid Platform is a FinOps platform that reads an organization's billing data in the FOCUS format, from its cloud bills and from Costroid's rows, into one ledger. It is not open yet.

Nothing in Costroid needs it. The check, the comment, the budget and the rows run in your CI with your keys, and [`docs/export.md`](export.md) lists every way the rows leave the job.

When the `report` stage is given Costroid Platform's address in the action's `platform-url` input, the link opens the pull request there instead of this page.
